DaVinci Resolve Free 21.1.1 — macOS Bridge Architecture

File-Mailbox (loadfile) + Fusion.prefs two-way IPC for Resolve Free 21.1.1

Technical Architecture for DaVinci Resolve Free 21.1 / 21.1.1:

Resolve 19.1 restricted UIManager to Studio, and Resolve 21.1 disabled Python (.py) scripts in the Free tier while sandboxing Lua (blocking io.open, os.execute, and require).

How Our Bridge Works: Resolve Free 21.1.1 still runs .lua scripts from Workspace ▸ Scripts with access to resolve, MediaPool, Timeline, Fusion, loadfile(), and fusion:SavePrefs(). Our resident script (VFXKit_ResolveFree_Bridge.lua) polls commands via loadfile() and returns JSON through Fusion.prefs in ~50ms.
